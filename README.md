# Начало работы с проектом

Этот проект был создан с помощью [Create React App](https://github.com/facebook/create-react-app).

На реализацию этого проекта ушло около восьми часов. Можно было быстрее, но у меня совсем не большой опыт работы с анимацией и я впервые пользуюсь библиотекой Swiper, в данной работе сделал акцен на скорость. Несмотря на то, что такой проект целесообразнее делать на чистых JS/HTML/CSS из‑за меньшего веса итогового бандла, я решил сделать его на React, потому что мне на нём комфортнее писать.


## Доступные команды

Перед запуском вам необходимо установить на свой компьютер [Node.js](https://nodejs.org/en/download)

Установите зависимости:

```
bun install
```

Запустите проект: 

```
bun start
```
